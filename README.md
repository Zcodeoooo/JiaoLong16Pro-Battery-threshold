## ⚙️ 使用说明

### 功能说明

自定义电池充电阈值策略：

```
当电量低于 [低阈值] 时开始充电 → 充至 [高阈值] 时停止充电
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `--low` | 充电启动阈值（百分比） |
| `--high` | 充电停止阈值（百分比） |
| `--allow-initial-discharge` | 允许初始放电（可选） |

---

## 🚀 操作步骤

> ⚠️ **重要提示**：以下命令需在 **Windows PowerShell（管理员权限）** 中执行

### 前置准备

取消微软 Microsoft 易受攻击驱动程序阻止列表：

1. 打开 **Windows 安全中心**
2. 进入 **设备安全性** → **内核隔离详细信息**
3. 关闭 **内存完整性** 或添加驱动白名单

---

### 设置充电阈值

```powershell
& 'NativeEnable.cmd' --low 60 --high 80 --allow-initial-discharge
```

**示例解读**：
- 电量降至 **60%** 以下时开始充电
- 电量达到 **80%** 时停止充电
- 允许首次执行时进行放电校准

---

### 取消充电阈值（恢复默认）

```powershell
& 'NativeDisable.cmd'
```

---

## 💡 建议阈值配置

| 使用场景 | 低阈值 (`--low`) | 高阈值 (`--high`) | 说明 |
|---------|-----------------|------------------|------|
| **日常办公** | 60% | 80% | 平衡电池寿命与续航 |
| **长期插电** | 50% | 70% | 最大化延长电池寿命 |
| **移动出行** | 40% | 95% | 保证最大续航能力 |
| **游戏高性能** | 30% | 100% | 确保满电状态 |

---

## ⚠️ 注意事项

1. **管理员权限**：必须以管理员身份运行 PowerShell
2. **驱动签名**：确保已禁用驱动程序强制签名或添加白名单
3. **备份 BIOS**：修改前建议备份原始 BIOS/EC 固件
4. **温度监控**：充电阈值调整可能影响电池温度，请注意监控
5. **恢复默认**：如需恢复出厂设置，运行 `NativeDisable.cmd`
